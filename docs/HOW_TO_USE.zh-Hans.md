# 如何使用 Imprint

[English](HOW_TO_USE.md) · [简体中文](HOW_TO_USE.zh-Hans.md) · [繁體中文](HOW_TO_USE.zh-Hant.md) · [日本語](HOW_TO_USE.ja.md)

Imprint 将操作系统镜像写入 USB 或 SD 卡。macOS、Linux 和 Windows 上的步骤相同。

**写入会清除所选磁盘上的全部数据。** 默认隐藏内置 / 系统磁盘。除非你明确知道目标是哪一块盘，否则不要关闭这项保护。

## 桌面应用

启动 **Imprint**。主窗口分三步：**镜像 → 目标 → 写入**。

### 1. 选择镜像

可用以下任一方式选择磁盘镜像：

- 在镜像卡片上点击 **选择**
- **文件 → 打开镜像…**（macOS 为 `⌘O`，Linux/Windows 为 `Ctrl+O`）
- 将镜像文件拖到窗口上

支持的文件：

| 类型 | 扩展名 |
|------|--------|
| 磁盘镜像 | `.iso`、`.img`、`.dmg`、`.raw`、`.bin` |
| 压缩包 | `.gz`、`.bz2`、`.xz`、`.zst`、`.zip`（以及 `.img.xz` 这类组合） |

卡片会显示文件名、类型和大小。若 Imprint 能读出压缩包的解压后大小，也会一并显示。

### 2. 选择磁盘

1. 插入 U 盘或 SD 卡（必要时使用读卡器）。
2. 在目标卡片上点击 **选择**，或使用 **文件 → 选择磁盘…**。
3. 选中可移动磁盘。再点另一块盘可同时写入多块。若磁盘未出现，点击 **刷新**。
4. 点击 **完成**。

容量小于镜像的磁盘会标为 **空间不足**，无法选中。内置磁盘默认隐藏，除非你在设置中改掉——请保持关闭。

Linux 上设备通常是 `/dev/sdX` 或 `/dev/nvmeXn1`。macOS 请优先使用 `/dev/rdiskN`。Windows 为 `\\.\PhysicalDriveN`。图形界面不需要这些路径；它们用于 [命令行](#命令行)。

### 3. 写入

1. 确认镜像名称和磁盘标签。
2. 点击 **写入**。所选磁盘上的数据将被清除。
3. 在管理员提示中授权：
   - **macOS：** Touch ID、Apple Watch 或密码
   - **Linux：** polkit（`pkexec`）或 `sudo`
   - **Windows：** UAC
4. 等待卸载 → 写入 → 可选校验 → 同步。
5. 需要中止时点击 **取消**。取消后的磁盘处于不完整状态，使用前请重新写入。

完成后磁盘即可启动。选 **再写一个** 换新镜像，或选 **保留镜像** 把同一文件写到另一块盘。

### 树莓派

需要官方 Raspberry Pi OS 镜像和首次启动选项（主机名、用户、Wi-Fi、SSH），又不想手写 `userconf` 时，用此模式。

1. 点击主窗口底部的 **Raspberry Pi** 栏，或 **文件 → Raspberry Pi…**（`⇧⌘R` / `Ctrl+Shift+R`）。
2. **设备** — 选择 Pi 型号，以便筛选兼容镜像。
3. **系统** — 选官方镜像，或 **使用自定义镜像** 选择本地 `.img` / `.iso` / 压缩文件。官方下载会缓存，同一镜像再次写入不会重新下载。
4. **选项** — 只打开写入后要应用的项：
   - 设置主机名
   - 设置用户名和密码
   - 配置 Wi-Fi（网络名称、密码、国家代码）
   - 启用 SSH（公钥可选）
   - 设置时区和键盘
5. **存储** — 选择 SD 卡或 USB 磁盘，然后 **写入**。

Imprint 会按需下载镜像并写入，再把首次启动文件叠加到 FAT 引导分区（cloud-init 或旧版 systemd，取决于镜像）。

随时点击返回箭头，回到普通写入界面。

### 设置

从标题栏齿轮、**Imprint → 设置…**，或 `⌘,` / `Ctrl+,` 打开 **设置**。

| 设置 | 作用 | 默认 |
|------|------|------|
| 外观 | 系统、浅色或深色 | 跟随操作系统 |
| 语言 | 界面语言 | 有对应翻译则用系统语言，否则英语 |
| 校验写入 | 写入后回读并逐字节比对 | 开 |
| 完成后弹出 | 写入结束后卸载磁盘 | 开 |
| 隐藏系统磁盘 | 不列出内置磁盘 | 开 |

界面语言：English、简体中文、繁體中文、日本語、한국어、Deutsch、Español、Français、Português。

### 键盘快捷键

| 操作 | macOS | Linux / Windows |
|------|-------|-----------------|
| 打开镜像 | `⌘O` | `Ctrl+O` |
| Raspberry Pi 模式 | `⇧⌘R` | `Ctrl+Shift+R` |
| 刷新磁盘 | `⌘R` | `Ctrl+R` |
| 设置 | `⌘,` | `Ctrl+,` |
| 退出 | `⌘Q` | `Ctrl+Q` |

**Imprint → 关于 Imprint** 显示版本，并可 **检查更新…**（仅打包版本）。

## 命令行

`imprint-cli` 是同一套写入流程，没有窗口。适合脚本、SSH 会话或救援环境。树莓派首次启动选项（主机名、Wi-Fi、SSH）仅图形界面提供。

列出可移动磁盘：

```bash
imprint-cli devices
```

包含系统磁盘（只读列出；代码层防护仍会拒绝写入系统盘）：

```bash
imprint-cli devices --all
```

写入。必须加上 `--yes`，避免误操作清空磁盘：

```bash
imprint-cli flash ubuntu.iso --device /dev/rdisk4 --yes
```

跳过逐字节校验，或写入后保持挂载：

```bash
imprint-cli flash raspios.img.xz --device /dev/sdc --yes --no-verify --no-eject
```

设备路径示例：

| 系统 | 典型路径 |
|------|----------|
| macOS | `/dev/rdiskN`（`diskutil list`） |
| Linux | `/dev/sdX` 或 `/dev/nvmeXn1` |
| Windows | `\\.\PhysicalDriveN` |

打开原始磁盘时，命令行仍会请求管理员 / root 权限。也可以用 `sudo` /「以管理员身份运行」。

从源码目录运行：

```bash
cargo run -p imprint-cli -- devices
cargo run -p imprint-cli -- flash ubuntu.iso --device /dev/rdisk4 --yes
```

## 权限

打开原始磁盘需要提升权限。Imprint 在写入时才会请求；图形界面不必以 root 启动。

若取消提示，写入不会开始。若提权失败，确认本机可以批准管理员对话框（Linux 上的 polkit，macOS/Windows 上的管理员账户）。

## 出了问题怎么办

| 现象 | 可尝试 |
|------|--------|
| 未找到可移动磁盘 | 拔出再插入磁盘，然后 **刷新**。确认系统把它挂成可移动设备，而不是内置卷。 |
| 磁盘「空间不足」 | 镜像（解压后）大于磁盘。换更大的卡或更小的镜像。 |
| 不支持的镜像 | 使用 `.iso` / `.img` / `.dmg` 或上文列出的压缩格式。 |
| 需要管理员权限 | 批准提示，或用 `sudo` / 管理员身份运行命令行。 |
| 校验失败 | 回读与写入不一致。换线、换口或换盘；SD 卡和廉价 U 盘比主机更容易出这个问题。 |
| Raspberry Pi 目录加载失败 | 检查网络后点 **重试**。也可以 **使用自定义镜像** 选择本地文件。 |
| 下载 / 校验和失败 | 重新下载。校验和失败表示文件被截断或损坏。 |
| 写入已取消 | 该盘无法启动。请重新写入。 |

默认开启校验。仅在你清楚关闭后要等到目标无法启动才会发现坏写入时，才在设置中关掉。
