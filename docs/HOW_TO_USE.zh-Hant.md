# 如何使用 Imprint

[English](HOW_TO_USE.md) · [简体中文](HOW_TO_USE.zh-Hans.md) · [繁體中文](HOW_TO_USE.zh-Hant.md) · [日本語](HOW_TO_USE.ja.md)

Imprint 將作業系統映像檔寫入 USB 或 SD 卡。macOS、Linux 與 Windows 上的步驟相同。

**寫入會清除所選磁碟上的所有資料。** 預設隱藏內建 / 系統磁碟。除非你明確知道目標是哪一塊磁碟，否則不要關閉這項保護。

## 桌面應用程式

啟動 **Imprint**。主視窗分三步：**映像檔 → 目標 → 寫入**。

### 1. 選擇映像檔

可用以下任一方式選擇磁碟映像檔：

- 在映像檔卡片上點選 **選擇**
- **檔案 → 打開映像檔…**（macOS 為 `⌘O`，Linux/Windows 為 `Ctrl+O`）
- 將映像檔拖到視窗上

支援的檔案：

| 類型 | 副檔名 |
|------|--------|
| 磁碟映像檔 | `.iso`、`.img`、`.dmg`、`.raw`、`.bin` |
| 壓縮檔 | `.gz`、`.bz2`、`.xz`、`.zst`、`.zip`（以及 `.img.xz` 這類組合） |

卡片會顯示檔名、類型與大小。若 Imprint 能讀出壓縮檔解壓後的大小，也會一併顯示。

### 2. 選擇磁碟

1. 插入 USB 隨身碟或 SD 卡（必要時使用讀卡機）。
2. 在目標卡片上點選 **選擇**，或使用 **檔案 → 選擇磁碟…**。
3. 選取可移除磁碟。再點另一塊磁碟可同時寫入多塊。若磁碟未出現，點選 **重新整理**。
4. 點選 **完成**。

容量小於映像檔的磁碟會標為 **空間不足**，無法選取。內建磁碟預設隱藏，除非你在設定中改掉——請保持關閉。

Linux 上裝置通常是 `/dev/sdX` 或 `/dev/nvmeXn1`。macOS 請優先使用 `/dev/rdiskN`。Windows 為 `\\.\PhysicalDriveN`。圖形介面不需要這些路徑；它們用於 [命令列](#命令列)。

### 3. 寫入

1. 確認映像檔名稱與磁碟標籤。
2. 點選 **寫入**。所選磁碟上的資料將被清除。
3. 在系統管理員提示中授權：
   - **macOS：** Touch ID、Apple Watch 或密碼
   - **Linux：** polkit（`pkexec`）或 `sudo`
   - **Windows：** UAC
4. 等待卸載 → 寫入 → 可選驗證 → 同步。
5. 需要中止時點選 **取消**。取消後的磁碟處於不完整狀態，使用前請重新寫入。

完成後磁碟即可開機。選 **再寫一個** 換新映像檔，或選 **保留映像檔** 把同一檔案寫到另一塊磁碟。

### 樹莓派

需要官方 Raspberry Pi OS 映像檔與首次開機選項（主機名稱、使用者、Wi-Fi、SSH），又不想手寫 `userconf` 時，使用此模式。

1. 點選主視窗底部的 **Raspberry Pi** 列，或 **檔案 → Raspberry Pi…**（`⇧⌘R` / `Ctrl+Shift+R`）。
2. **裝置** — 選擇 Pi 型號，以便篩選相容映像檔。
3. **系統** — 選官方映像檔，或 **使用自訂映像檔** 選擇本機 `.img` / `.iso` / 壓縮檔。官方下載會快取，同一映像檔再次寫入不會重新下載。
4. **選項** — 只開啟寫入後要套用的項目：
   - 設定主機名稱
   - 設定使用者名稱和密碼
   - 設定 Wi-Fi（網路名稱、密碼、國家代碼）
   - 啟用 SSH（公開金鑰可選）
   - 設定時區和鍵盤
5. **儲存** — 選擇 SD 卡或 USB 磁碟，然後 **寫入**。

Imprint 會依需要下載映像檔並寫入，再把首次開機檔案疊加到 FAT 開機分割區（cloud-init 或舊版 systemd，取決於映像檔）。

隨時點選返回箭頭，回到一般寫入畫面。

### 設定

從標題列齒輪、**Imprint → 設定…**，或 `⌘,` / `Ctrl+,` 開啟 **設定**。

| 設定 | 作用 | 預設 |
|------|------|------|
| 外觀 | 系統、淺色或深色 | 跟隨作業系統 |
| 語言 | 介面語言 | 有對應翻譯則用系統語言，否則英語 |
| 驗證寫入 | 寫入後回讀並逐位元組比對 | 開 |
| 完成後退出 | 寫入結束後卸載磁碟 | 開 |
| 隱藏系統磁碟 | 不列出內建磁碟 | 開 |

介面語言：English、简体中文、繁體中文、日本語、한국어、Deutsch、Español、Français、Português。

### 鍵盤快速鍵

| 操作 | macOS | Linux / Windows |
|------|-------|-----------------|
| 打開映像檔 | `⌘O` | `Ctrl+O` |
| Raspberry Pi 模式 | `⇧⌘R` | `Ctrl+Shift+R` |
| 重新整理磁碟 | `⌘R` | `Ctrl+R` |
| 設定 | `⌘,` | `Ctrl+,` |
| 結束 | `⌘Q` | `Ctrl+Q` |

**Imprint → 關於 Imprint** 顯示版本，並可 **檢查更新…**（僅套件版）。

## 命令列

`imprint-cli` 是同一套寫入流程，沒有視窗。適合腳本、SSH 工作階段或救援環境。樹莓派首次開機選項（主機名稱、Wi-Fi、SSH）僅圖形介面提供。

列出可移除磁碟：

```bash
imprint-cli devices
```

包含系統磁碟（唯讀列出；程式碼層防護仍會拒絕寫入系統磁碟）：

```bash
imprint-cli devices --all
```

寫入。必須加上 `--yes`，避免誤操作清空磁碟：

```bash
imprint-cli flash ubuntu.iso --device /dev/rdisk4 --yes
```

跳過逐位元組驗證，或寫入後保持掛載：

```bash
imprint-cli flash raspios.img.xz --device /dev/sdc --yes --no-verify --no-eject
```

裝置路徑範例：

| 系統 | 典型路徑 |
|------|----------|
| macOS | `/dev/rdiskN`（`diskutil list`） |
| Linux | `/dev/sdX` 或 `/dev/nvmeXn1` |
| Windows | `\\.\PhysicalDriveN` |

開啟原始磁碟時，命令列仍會請求系統管理員 / root 權限。也可以用 `sudo` /「以系統管理員身分執行」。

從原始碼目錄執行：

```bash
cargo run -p imprint-cli -- devices
cargo run -p imprint-cli -- flash ubuntu.iso --device /dev/rdisk4 --yes
```

## 權限

開啟原始磁碟需要提升權限。Imprint 在寫入時才會請求；圖形介面不必以 root 啟動。

若取消提示，寫入不會開始。若提權失敗，確認本機可以批准系統管理員對話框（Linux 上的 polkit，macOS/Windows 上的系統管理員帳戶）。

## 出了問題怎麼辦

| 現象 | 可嘗試 |
|------|--------|
| 找不到可移除的磁碟 | 拔出再插入磁碟，然後 **重新整理**。確認系統把它掛成可移除裝置，而不是內建卷宗。 |
| 磁碟「空間不足」 | 映像檔（解壓後）大於磁碟。換更大的卡或更小的映像檔。 |
| 不支援的映像檔 | 使用 `.iso` / `.img` / `.dmg` 或上文列出的壓縮格式。 |
| 需要系統管理員權限 | 批准提示，或用 `sudo` / 系統管理員身分執行命令列。 |
| 驗證失敗 | 回讀與寫入不一致。換線、換埠或換碟；SD 卡與廉價 USB 隨身碟比主機更容易出這個問題。 |
| Raspberry Pi 目錄載入失敗 | 檢查網路後點 **重試**。也可以 **使用自訂映像檔** 選擇本機檔案。 |
| 下載 / 校驗和失敗 | 重新下載。校驗和失敗表示檔案被截斷或損壞。 |
| 寫入已取消 | 該磁碟無法開機。請重新寫入。 |

預設開啟驗證。僅在你清楚關閉後要等到目標無法開機才會發現損壞寫入時，才在設定中關掉。
