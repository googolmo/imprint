# Imprint の使い方

[English](HOW_TO_USE.md) · [简体中文](HOW_TO_USE.zh-Hans.md) · [繁體中文](HOW_TO_USE.zh-Hant.md) · [日本語](HOW_TO_USE.ja.md)

Imprint は OS イメージを USB ドライブまたは SD カードに書き込みます。手順は macOS、Linux、Windows で同じです。

**書き込むと選択したドライブの内容はすべて消去されます。** 内蔵 / システムディスクはデフォルトで非表示です。対象ディスクを正確に把握している場合を除き、この保護はオフにしないでください。

## デスクトップアプリ

**Imprint** を起動します。メインウィンドウは 3 段階です：**イメージ → ターゲット → 書き込む**。

### 1. イメージを選ぶ

次のいずれかの方法でディスクイメージを選べます。

- イメージカードの **選択** をクリック
- **ファイル → イメージを開く…**（macOS は `⌘O`、Linux/Windows は `Ctrl+O`）
- イメージファイルをウィンドウへドラッグ

対応ファイル：

| 種類 | 拡張子 |
|------|--------|
| ディスクイメージ | `.iso`、`.img`、`.dmg`、`.raw`、`.bin` |
| 圧縮 | `.gz`、`.bz2`、`.xz`、`.zst`、`.zip`（`.img.xz` のような組み合わせも含む） |

カードにはファイル名、種類、サイズが表示されます。圧縮イメージは、Imprint が展開後サイズを読める場合も表示します。

### 2. ドライブを選ぶ

1. USB メモリまたは SD カードを接続します（必要ならカードリーダーを使います）。
2. ターゲットカードの **選択** をクリックするか、**ファイル → ドライブを選択…** を使います。
3. 取り外し可能なディスクを選びます。別のディスクをクリックすると同時に複数へ書き込めます。表示されない場合は **更新** をクリックします。
4. **完了** をクリックします。

イメージより小さいドライブは **容量不足** と表示され、選択できません。内蔵ディスクは設定を変えない限り非表示です。オフのままにしてください。

Linux ではデバイスは通常 `/dev/sdX` または `/dev/nvmeXn1` です。macOS では `/dev/rdiskN` を使ってください。Windows では `\\.\PhysicalDriveN` です。GUI ではこれらのパスは不要です。[コマンドライン](#コマンドライン) で使います。

### 3. 書き込む

1. イメージ名とドライブのラベルを確認します。
2. **書き込む** をクリックします。選択したドライブは消去されます。
3. 管理者プロンプトを承認します：
   - **macOS：** Touch ID、Apple Watch、またはパスワード
   - **Linux：** polkit（`pkexec`）または `sudo`
   - **Windows：** UAC
4. アンマウント → 書き込み → 任意の検証 → 同期が終わるまで待ちます。
5. 中止する場合は **キャンセル** をクリックします。キャンセルしたドライブは不完全な状態です。使う前に再度書き込んでください。

完了すると、そのドライブから起動できます。新しいイメージには **続けて書き込む**、同じファイルを別のディスクへ書くには **イメージを保持** を選びます。

### Raspberry Pi

公式 Raspberry Pi OS イメージと初回起動オプション（ホスト名、ユーザー、Wi-Fi、SSH）が必要で、`userconf` を手書きしたくないときに使います。

1. メインウィンドウ下部の **Raspberry Pi** バー、または **ファイル → Raspberry Pi…**（`⇧⌘R` / `Ctrl+Shift+R`）をクリックします。
2. **デバイス** — Pi のモデルを選び、対応イメージを絞り込みます。
3. **OS** — 公式イメージを選ぶか、**カスタムを使用** でローカルの `.img` / `.iso` / 圧縮ファイルを選びます。公式ダウンロードはキャッシュされ、同じイメージの再書き込みでは再ダウンロードしません。
4. **オプション** — 書き込み後に適用したい項目だけオンにします：
   - ホスト名を設定
   - ユーザー名とパスワードを設定
   - Wi-Fi を設定（ネットワーク名、パスワード、国コード）
   - SSH を有効化（公開鍵は任意）
   - タイムゾーンとキーボードを設定
5. **ストレージ** — SD カードまたは USB ディスクを選び、**書き込む** をクリックします。

Imprint は必要ならイメージをダウンロードして書き込み、初回起動ファイルを FAT ブートパーティションへ重ねます（イメージに応じて cloud-init または旧 systemd）。

戻る矢印でいつでも通常の書き込み画面に戻れます。

### 設定

タイトルバーの歯車、**Imprint → 設定…**、または `⌘,` / `Ctrl+,` から **設定** を開きます。

| 設定 | 内容 | デフォルト |
|------|------|------------|
| 外観 | システム、ライト、ダーク | OS に従う |
| 言語 | UI 言語 | 翻訳がある場合は OS の言語、なければ英語 |
| 書き込みを検証 | 書き込み後に全バイトを読み戻して比較 | オン |
| 成功後に取り出す | 書き込み完了後にドライブをアンマウント | オン |
| システムドライブを隠す | 内蔵ディスクを一覧に出さない | オン |

UI 言語：English、简体中文、繁體中文、日本語、한국어、Deutsch、Español、Français、Português。

### キーボードショートカット

| 操作 | macOS | Linux / Windows |
|------|-------|-----------------|
| イメージを開く | `⌘O` | `Ctrl+O` |
| Raspberry Pi モード | `⇧⌘R` | `Ctrl+Shift+R` |
| ドライブを更新 | `⌘R` | `Ctrl+R` |
| 設定 | `⌘,` | `Ctrl+,` |
| 終了 | `⌘Q` | `Ctrl+Q` |

**Imprint → Imprint について** でバージョンを確認し、**アップデートを確認…** できます（パッケージ版のみ）。

## コマンドライン

`imprint-cli` は同じ書き込みパイプラインをウィンドウなしで実行します。スクリプト、SSH、復旧シェル向けです。Raspberry Pi の初回起動オプション（ホスト名、Wi-Fi、SSH）は GUI のみです。

取り外し可能なディスクを一覧表示：

```bash
imprint-cli devices
```

システムディスクも含める（読み取り専用の一覧。コード上のガードはシステムディスクへの書き込みを拒否します）：

```bash
imprint-cli devices --all
```

書き込み。誤操作でディスクを消さないよう `--yes` が必須です：

```bash
imprint-cli flash ubuntu.iso --device /dev/rdisk4 --yes
```

バイト単位の検証をスキップする、または完了後もマウントしたままにする：

```bash
imprint-cli flash raspios.img.xz --device /dev/sdc --yes --no-verify --no-eject
```

デバイスパスの例：

| OS | 典型的なパス |
|----|----------------|
| macOS | `/dev/rdiskN`（`diskutil list`） |
| Linux | `/dev/sdX` または `/dev/nvmeXn1` |
| Windows | `\\.\PhysicalDriveN` |

CLI も生ディスクを開くときに管理者 / root 権限を求めます。`sudo` / 「管理者として実行」でも起動できます。

ソースチェックアウトから：

```bash
cargo run -p imprint-cli -- devices
cargo run -p imprint-cli -- flash ubuntu.iso --device /dev/rdisk4 --yes
```

## 権限

生のディスクを開くには昇格した権限が必要です。Imprint は書き込み時に要求します。GUI を root で始める必要はありません。

プロンプトをキャンセルすると書き込みは始まりません。昇格に失敗した場合は、このマシンで管理者ダイアログを承認できるか確認してください（Linux では polkit、macOS/Windows では管理者アカウント）。

## うまくいかないとき

| 表示 | 試すこと |
|------|----------|
| 取り外し可能なドライブが見つかりません | ディスクを抜き差しして **更新**。OS が取り外し可能としてマウントしているか確認します。 |
| ドライブが「容量不足」 | イメージ（展開後）がディスクより大きいです。大きいカードか小さいイメージを選んでください。 |
| 未対応のイメージ | `.iso` / `.img` / `.dmg`、または上に挙げた圧縮形式を使ってください。 |
| 管理者権限が必要 | プロンプトを承認するか、CLI を `sudo` / 管理者として実行します。 |
| 検証に失敗 | 読み戻しが書き込みと一致しません。ケーブル、ポート、ディスクを変えてみてください。SD カードや安価な USB メモリはホストより失敗しやすいです。 |
| Raspberry Pi カタログの読み込み失敗 | ネットワークを確認して **再試行**。**カスタムを使用** でローカルファイルも選べます。 |
| ダウンロード / チェックサム失敗 | ダウンロードをやり直してください。チェックサム失敗はファイルが途中で切れているか壊れていることを意味します。 |
| 書き込みはキャンセルされました | そのディスクは起動できません。再度書き込んでください。 |

検証はデフォルトでオンです。オフにすると、対象が起動に失敗するまで不良書き込みに気づけません。その意味を理解したときだけ設定でオフにしてください。
